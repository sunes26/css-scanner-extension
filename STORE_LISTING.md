🔍 CSS Scanner - The Ultimate CSS Inspection Tool for Developers & Designers

Inspect, analyze, and copy CSS styles from any website instantly. CSS Scanner helps web developers and designers understand styling by providing real-time CSS property inspection with a beautiful, organized interface.

⭐ KEY FEATURES

✅ REAL-TIME CSS INSPECTION
• Hover over any element to instantly view its CSS properties
• Click to pin the CSS panel for detailed analysis
• Drag pinned panels to reposition them anywhere on screen
• See all computed styles organized by category

✅ SMART CATEGORIZATION
CSS properties automatically organized into 7 intuitive categories:
📐 Layout - display, position, float, z-index, overflow
📦 Box Model - width, height, margin, padding
🔲 Border - border properties, border-radius, outline
🎨 Background - colors, gradients, images, blend modes
📝 Typography - fonts, text properties, line-height
📊 Flex & Grid - flexbox and CSS Grid properties
✨ Effects - opacity, transforms, transitions, animations

✅ ONE-CLICK COPY
• Copy CSS selectors instantly
• Copy all computed styles at once
• Copy inline styles separately
• Works with fallback methods for maximum compatibility

✅ DEVELOPER-FRIENDLY
• CSS selector generation for precise element targeting
• Element tag, ID, and class information
• Inline vs computed styles clearly separated
• Keyboard shortcut support (ESC to exit)

✅ PERFORMANCE OPTIMIZED

• Built-in performance monitoring
• Minimal memory footprint

✅ PRIVACY & SECURITY FIRST

✅ BEAUTIFUL UI/UX

🚀 HOW TO USE

1. Click the extension icon to activate scan mode
2. Hover over any element on the webpage
3. View CSS properties in the popup panel
4. Click an element to pin the panel
5. Drag the pinned panel by the green header
6. Copy selectors or CSS with one click
7. Press ESC to exit scan mode
